# Tool argument check

A short labelling task: an assistant fills in a tool (for example a web search or a calendar entry) for a situation,
and you judge whether what it filled in is **correct**, **partial** or **incorrect** compared with a reference answer.

Open the page: https://andreas-hum.github.io/ai_assistant/

Your progress is saved in your browser. Your answers and the name you type are sent automatically to a Google Form
(every 10 answers and when you finish); nothing else is collected. If sending fails, the page offers a download instead.
